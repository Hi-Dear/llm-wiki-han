# 4-Step 투자 대시보드

사용자가 주식 투자를 판단할 때 쓰는 4단계 체크리스트를 한 곳에서 확인할 수 있게 만든 대시보드. 여러 사이트를 일일이 열어봐야 했던 문제를 해결하기 위해, 클라우드 루틴이 매일 아침 자동으로 데이터를 갱신한다.

두 가지 버전이 독립적으로 존재한다:
- **[웹 (GitHub Pages)](https://hi-dear.github.io/llm-wiki-han/)** — 실사용 메인. 디자인 자유도·모바일 반응성이 더 좋아 Notion 논의 끝에 새로 만듦
- **Notion** — 먼저 만들었던 버전. 계속 유지하되 스케줄은 그대로 둠(웹과 서로 영향 없음)

## 4단계 프레임워크

1. **거시 환경 확인** — 버핏지수(시가총액/GDP), 쉴러 PER(CAPE), 공포·탐욕 지수
2. **개별종목 밸류에이션** — PER, PBR, PEG, PSR, EV/EBITDA
3. **재무 건전성** — 부채비율, ROE, FCF
4. **매매 타이밍** — 이동평균선(20·60·120일) 대비 위치, RSI, 거래량

## 구조

- **웹 (`docs/`, 이 저장소)**: 빌드 도구 없는 순수 HTML/CSS/JS 정적 사이트. `docs/index.html`이 `docs/data/dashboard.json`을 fetch해서 렌더링. GitHub Pages(마스터 브랜치 `/docs` 폴더)로 배포
- **Notion**: 워크스페이스의 "금융" 페이지 하위 "4-Step 투자 대시보드" 페이지 (기존에 있던 TradingView 히트맵 페이지와 같은 상위 페이지를 공유)
- **① 거시환경**: 버핏지수·쉴러PER·공포탐욕지수 3개 지표를 스탯 타일/표로 표시
- **②③④ 종목 지표**: 뉴스 브리핑([[news-2026-08-07]] 등)과 동일한 고정 20종목(미국 10 + 국내 10)을 종목당 한 행으로 관리하며, 밸류에이션·재무건전성·매매타이밍 컬럼을 한 화면에서 비교할 수 있다 (웹은 표, Notion은 데이터베이스로 동일한 구조를 구현)
- 자동 매수/매도 판정은 넣지 않는다 — 데이터를 모아 보여줄 뿐 최종 판단은 사용자 몫

## 운영 방식

- **웹**: 클라우드 루틴 "4-Step 투자 대시보드 갱신 (웹)"이 매일 KST 08:30경 자동 실행되어 웹 검색으로 지표를 조사하고 `docs/data/dashboard.json`을 직접 커밋·푸시한다
- **Notion**: 클라우드 루틴 "4-Step 투자 대시보드 갱신"이 매일 KST 08:15경 자동 실행되어 Notion 페이지·데이터베이스를 직접 갱신한다 (저장소 파일은 건드리지 않음)
- 두 루틴은 완전히 독립적이다 — 같은 데이터를 각자 따로 웹검색하므로 리서치가 중복되고 두 곳 수치가 미세하게 다를 수 있음을 감수하고, 서로 영향받지 않게 분리해둔 상태 (추후 필요시 통합 고려)
- 기존 "매일 아침 뉴스 브리핑" 루틴과 동일한 수치 정확도 원칙(2개 이상 출처 교차검증, 불확실한 값은 "약"/null·"확인 필요" 표기, 단일 출처는 각주 명시)을 두 루틴 모두에 적용한다
- 이 위키 페이지 자체는 구조·운영방식을 설명하는 정적 페이지이며, 실제 수치는 웹/Notion 쪽에서만 매일 갱신된다(위키 파일을 매일 새로 만들지 않음)
